# kube-node-labels (archived)

> **Archived (INFRA-3069).** This standalone fork is no longer maintained.
> Image builds live in [`gathertown/infra-utils`](https://github.com/gathertown/infra-utils)
> under `docker-images/kube-node-labels/` (`alpine:3.24`, CircleCI multi-arch push to
> `gathertown/kube-node-labels:<sha>`).

Consumers should pin a sha tag from that pipeline (for example
`gathertown/kube-node-labels:101c13819`), not a tag built from this repo.

Upstream source: [scottcrossen/kube-node-labels](https://github.com/scottcrossen/kube-node-labels).
